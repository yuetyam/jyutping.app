How to uninstall Jyutping Input Method for Windows

Before you uninstall:
  • Switch from the current input method to another one.
  • Save all your work on the computer and close all apps.

Uninstall the input method

Double-click C:\Program Files\Jyutping\unins000.exe to start uninstalling.

If a prompt says an app cannot be closed during the process:
Try signing out and signing back in (or restarting the computer), then start uninstalling again.

When it is done, it is best to restart the computer.


Clean up personal data (optional)

After uninstalling the input method app and restarting the computer, you can also clean up the data related to Jyutping:

A. Input memory
  1. Press Win + R, enter the path %LOCALAPPDATA%, then press Enter ⏎
  2. Find the Jyutping folder and delete it. If there is none, skip this.

B. Input method logs
  1. Press Win + R, enter the path %TEMP%, then press Enter ⏎
  2. Find the Jyutping folder and delete it. If there is none, skip this.

C. Input method settings
  1. Open the registry editor: press Win + R, enter regedit, then press Enter ⏎
  2. Go to HKEY_CURRENT_USER\Software\Jyutping
  3. Right-click Jyutping, choose Delete, and confirm.

Once everything is done, it is best to restart the computer.
